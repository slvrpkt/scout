Scout · runs on your own computer

Scout Architecture

Scout finds job postings, scores each one against your profile, writes a tailored resume and cover letter for the good ones, and keeps a log of what you applied for. It is one program (the Scout server) and one database, both on this Windows computer at localhost:3000. It reaches out to the internet only for the services you set up: your AI provider, JSearch and your Google account.

① Gatekeeper

The first thing every request meets. If you're not signed in, it sends you to the sign-in page. It also tells your browser to load nothing from outside Scout, so no trackers or ads can load. (In the code it's called the "proxy".)

Like: the front-desk check before you enter a building.

④ Background worker

Writing a resume takes the AI a minute. Instead of freezing the screen, Scout puts that work on a to-do list in the database, and the worker does it in the background, a few at a time. If Scout is closed halfway, the unfinished item is marked and can be retried. (In the code it's the "job runner".)

Like: handing a ticket to a kitchen: you're free to keep browsing while it's prepared.

⑤ Clock

Starts work on its own at set times: the agent's searches, the 03:00 backup, the Sheet sync, the inbox check. It doesn't do the work itself; it hands it to the worker.

Like: an alarm that puts tickets on the kitchen's list.

3 · Two places things are kept

The database and the files folder are different jobs

Both are on this computer. The database is Scout's memory; the files folder only holds files Scout makes from that memory.

Database (PostgreSQL)

What it is
A program that stores records in tables, like a set of linked spreadsheets that Scout can search instantly.
What's in it
Everything you see in Scout: your profile, every application and its resume and letter (and every version), postings and scores, emails, settings, and the background worker's to-do list.
Where
Inside the PostgreSQL program (from scoop), not as files you open.
If it's lost
Scout is empty. That's what backups are for.

Files folder (data)

What it is
An ordinary folder in the project: data\backups.
What's in it
One backup file per night (a full copy of the database), the last 14 kept; and zipped PDFs when you download many at once.
Where
On disk, next to the code; a copy of each backup also goes to "Scout backups" in Google Drive.
If it's lost
Nothing in Scout changes; you just lose those backup copies.
