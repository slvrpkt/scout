# Contributing to Scout

Glad you're here. [DEVELOPMENT.md](DEVELOPMENT.md) explains how to set Scout up and run its tests.

## Found a bug or have an idea?

Tell me through the [issue forms](https://github.com/slvrpkt/scout/issues/new/choose): one for bugs, one for ideas. That's the best way to reach me.

You're also welcome to send a pull request, whether it fixes a bug or adds an improvement you'd like to see. Either way, open an issue too, so I know what it's for.

## What happens to your pull request

1. You open a pull request.
2. When I get a chance, I look at it and test it. I can't promise a timeframe: it could be days or it could be weeks.
3. If it makes sense for Scout, I bring it into the next release myself and credit you in the release notes. Your pull request is then closed with a link to that release, rather than merged.

Thanks for helping make Scout better.
